KBT Token Contract

Overview

Standard ERC-20 token with 1.5 billion fixed supply. No minting after deployment.

Contract Interface

Solidity Interface
interface IKBT { function totalSupply() external view returns (uint256); function balanceOf(address account) external view returns (uint256); function transfer(address to, uint256 amount) external returns (bool); function approve(address spender, uint256 amount) external returns (bool); function transferFrom(address from, address to, uint256 amount) external returns (bool); function allowance(address owner, address spender) external view returns (uint256); }

Reading Token Balance

JavaScript (ethers.js v5)
const { ethers } = require('ethers'); const KBT_ADDRESS = "0x27533fEF27f07224e746705Da19243f89Dc36D81"; const KBT_ABI = [ "function balanceOf(address) view returns (uint256)", "function transfer(address to, uint256 amount) returns (bool)", "function approve(address spender, uint256 amount) returns (bool)" ]; const provider = new ethers.providers.Web3Provider(window.ethereum); const signer = provider.getSigner(); const kbtContract = new ethers.Contract(KBT_ADDRESS, KBT_ABI, signer); // Get balance const balance = await kbtContract.balanceOf(address); console.log("KBT Balance:", ethers.utils.formatEther(balance));

Transferring Tokens

JavaScript Example
const wallet = new ethers.Wallet('YOUR_PRIVATE_KEY', provider); const contractWithSigner = kbtContract.connect(wallet); const recipient = '0xRecipientAddress'; const amount = ethers.utils.parseEther('100'); // 100 KBT const tx = await contractWithSigner.transfer(recipient, amount); await tx.wait(); console.log('Transfer complete:', tx.hash);

Presale Contract

How to Participate

The presale contract accepts ETH, USDT, and USDC. Here's how to buy KBT tokens:

Buying with ETH

JavaScript
const PRESALE_ADDRESS = "0xF71e278443EBb18165a33Cf844bD9fDe8842B574"; const presaleAbi = ['function buyWithETH() payable']; const contract = new ethers.Contract(PRESALE_ADDRESS, presaleAbi, signer); // Buy with 0.1 ETH const tx = await contract.buyWithETH({ value: ethers.utils.parseEther('0.1') }); await tx.wait(); console.log('Purchase successful!');

Buying with USDT

JavaScript
const PRESALE_ADDRESS = "0xF71e278443EBb18165a33Cf844bD9fDe8842B574"; const USDT_ADDRESS = "0xea70e6d9579110a965bEf06ff01d03216F5Ee1F1"; // 1. Approve USDT const usdtContract = new ethers.Contract(USDT_ADDRESS, ERC20_ABI, signer); const amount = ethers.utils.parseUnits("100", 6); // 100 USDT (6 decimals) await usdtContract.approve(PRESALE_ADDRESS, amount); // 2. Buy KBT with referrer (optional) const presaleContract = new ethers.Contract(PRESALE_ADDRESS, PRESALE_ABI, signer); const referrer = "0x0000000000000000000000000000000000000000"; // No referrer await presaleContract.buyWithUSDT(amount, referrer);

Get Presale Info

JavaScript
const info = await presaleContract.getPresaleInfo(); console.log("Presale Start:", info.start); console.log("Current Stage:", info.stage); console.log("Tokens Sold:", ethers.utils.formatEther(info.tokensSold)); console.log("Stage Price:", ethers.utils.formatEther(info.stagePrice));

KBTPay Escrow Contract

Payment Flow

  1. Create payment intent via API
  2. Customer sends payment to merchant
  3. System records transaction hash
  4. Merchant receives payment (minus fee)
  5. Transaction tracked in dashboard

Creating a Payment

JavaScript - Create Payment Intent
// Create payment intent const response = await fetch('http://localhost:3000/api/transactions/create-intent', { method: 'POST', headers: { 'Content-Type': 'application/json' }, body: JSON.stringify({ merchantAddress: "0xYourMerchantAddress", customerAddress: userAddress, amount: ethers.utils.parseEther("1.0").toString(), tokenAddress: "0x0000000000000000000000000000000000000000", // ETH chainId: 11155111 }) }); const { paymentId } = await response.json();

Processing Payment

JavaScript - Send Transaction
// Send transaction const tx = await signer.sendTransaction({ to: merchantAddress, value: ethers.utils.parseEther("1.0") }); // Update transaction hash await fetch('http://localhost:3000/api/transactions/update-hash', { method: 'POST', headers: { 'Content-Type': 'application/json' }, body: JSON.stringify({ paymentId: paymentId, transactionHash: tx.hash }) });

Webhooks (Planned)

Webhooks will allow you to receive real-time notifications about payment events. Implementation planned for mainnet launch.

Event Types

  • payment.created - New payment initiated
  • payment.confirmed - Payment confirmed by merchant
  • payment.disputed - Payment disputed
  • payment.refunded - Payment refunded to customer
  • payment.completed - Payment successfully completed

React Integration with Wagmi

React Component
import { useAccount, useWriteContract, usePublicClient } from 'wagmi'; function BuyKBT() { const { address } = useAccount(); const { writeContractAsync } = useWriteContract(); const publicClient = usePublicClient(); async function buyTokens() { const PRESALE_ADDRESS = "0xF71e278443EBb18165a33Cf844bD9fDe8842B574"; const USDT_ADDRESS = "0xea70e6d9579110a965bEf06ff01d03216F5Ee1F1"; const amount = ethers.utils.parseUnits("100", 6); // Approve const approveTx = await writeContractAsync({ address: USDT_ADDRESS, abi: ERC20_ABI, functionName: 'approve', args: [PRESALE_ADDRESS, amount] }); await publicClient.waitForTransactionReceipt({ hash: approveTx }); // Buy const buyTx = await writeContractAsync({ address: PRESALE_ADDRESS, abi: PRESALE_ABI, functionName: 'buyWithUSDT', args: [amount, "0x0000000000000000000000000000000000000000"] }); await publicClient.waitForTransactionReceipt({ hash: buyTx }); } return <button onClick={buyTokens}>Buy KBT</button>; }

Full Payment Flow Example

Node.js Complete Example
const { ethers } = require('ethers'); // Setup const provider = new ethers.providers.Web3Provider(window.ethereum); const signer = provider.getSigner(); // Create payment intent async function createPayment(merchantAddr, amount) { const response = await fetch('http://localhost:3000/api/transactions/create-intent', { method: 'POST', headers: { 'Content-Type': 'application/json' }, body: JSON.stringify({ merchantAddress: merchantAddr, customerAddress: await signer.getAddress(), amount: amount.toString(), tokenAddress: "0x0000000000000000000000000000000000000000", chainId: 11155111 }) }); const { paymentId } = await response.json(); // Send transaction const tx = await signer.sendTransaction({ to: merchantAddr, value: amount }); // Update hash await fetch('http://localhost:3000/api/transactions/update-hash', { method: 'POST', headers: { 'Content-Type': 'application/json' }, body: JSON.stringify({ paymentId: paymentId, transactionHash: tx.hash }) }); return tx.hash; } // Use it const txHash = await createPayment('0xMerchant...', ethers.utils.parseEther('1.0')); console.log('Payment created:', txHash);
